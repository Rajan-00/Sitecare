# SiteCare AI

SiteCare AI is an intelligent website health monitoring, anomaly detection,
and predictive maintenance platform.

## Development phases

1. FastAPI backend foundation
2. PostgreSQL database and migrations
3. Authentication and authorization
4. Website management
5. Website monitoring engine
6. Scheduled background monitoring
7. Anomaly detection and maintenance prediction
8. React dashboard
9. Alerts and reports
10. Testing and deployment

## Current phase

Phase 1 provides a working FastAPI application with an automated health check.
